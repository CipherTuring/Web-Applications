Courses I'm Currently Taking

These are my courses that are part of my Computer Science Program at Yachay Tech University.

Distributed Systems

Instructor: Prof. Francisco Hidrobo

This course covers how independent computers coordinate and communicate to work as a single coherent system.

Main Topics

  1. Socket programming (TPC/UDP)
  2. Multihtreaded servers
  3. Network protocols and message passing

What I expect to learn

  • How to design a fault-tolerant client-server system
  • How to handle concurrency safely with threads
  • How to debug real network issues (sockets, ports, WSL2 networking)

Related resource: Beej's Guide to Network Programming

Note: That is one of my favorite authors, his books are awesome. I recommend it.

Machine Learning

Instructor: Prof. Juan Pablo Astudillo

An introduction to algorithms that learn patterns from data, including supervised and reinforcement learning approaches.

Main Topics

  1. Markov chains and reinforcement learning
  2. Model evaluation and experimentation
  3. Data preprocessing

What I expect to learn

  • How to implement and simulate Markov decision processes
  • How to design experiments and report results
  • How to fix and extend existing ML code templates

Cryptography

Instructor: Prof. Christian Iza

The mathematics and theory beyond the secret in the communications.

Main Topics

  1. Modular Arithmetic

What I expect to learn

  • How to design strong cryptographical systems
  • Get a betters understanding of how to make secure a communication
  • Learn the theoretical aspects of Cryptography
